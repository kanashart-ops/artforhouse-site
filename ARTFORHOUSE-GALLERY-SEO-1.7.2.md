# Art For House — названия и alt для галереи (SEO 1.7.2)

Названия в `data/gallery-seo/*.json` подготовлены по изображениям из истории
GitHub. Для 126 исходных изображений есть индивидуальное описание.

Сайт подставляет название/alt только если сохранённое название совпадает с
кодом файла (например, `a1`, `aa7`). Собственные названия художницы не
переопределяются. Оригинальные URL, категории, ID, Vercel Blob и PostgreSQL не
изменяются. Это серверное отображение SEO-подписей, а не миграция данных БД.

Не распознаны по исходным изображениям `x16`, `s14`, `s16`: они остаются
без нового предложенного названия. Дополнительные записи PostgreSQL вне
каталога `data/gallery.json` не переименовываются без проверки фотографии.

Для постоянного сохранения предложенных подписей в PostgreSQL можно открыть
соответствующую запись в админке и нажать «Сохранить изменения»,
поскольку в форму подставляется новое название и alt. При этом сохраняется ID,
ссылка на изображение и категория.

Изменять названия вручную можно в `/admin`: пользовательское название будет
иметь приоритет над этим SEO-каталогом.
